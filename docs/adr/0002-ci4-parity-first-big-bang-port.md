# Migrate to CodeIgniter 4.7 as a parity-first, big-bang port

CodeIgniter 3 (3.1.10, security-fixes-only since 2022) cannot carry us to the PHP 8.5.12 target (ADR-0001). We chose **CodeIgniter 4.7** over rebuilding on Laravel/Symfony: the official CI3→CI4 upgrade guides map our six controllers across, versus reinventing routing, models, and validation from scratch for the same PHP outcome. Strategy: **strict 1:1 feature parity** — the old app is the behavioral oracle — with **idiomatic CI4 where behavior is identical** (explicit routes, `Model` + Query Builder, Services, `.env` config), and the **hand-rolled session auth ported as-is**. Execution is a single big-bang branch with a maintenance-window cutover (self-hosted; downtime accepted); no interim CI3/PHP 8.2 stepping stone. Deferred improvements become backlog issues, not migration scope.
